# Define Goal

Produce and maintain: North Star, current state, target state, acceptance criteria, invariants, constraints, risk register, dependencies, phased execution graph and scorecard. Preserve the business/system outcome behind the task. If implementation is available in the same environment, proceed after defining the goal rather than stopping at planning.
